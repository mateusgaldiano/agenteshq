Política de Privacidade — Doze Cadeiras Mei

Última atualização: 2 de novembro de 2026

1. O que é o app

O Doze Cadeiras Mei é uma ferramenta de uso pessoal do autor do projeto Doze Cadeiras. Ela roda apenas no computador do autor e serve para publicar vídeos curtos do livro nos canais do próprio projeto (@dozecadeiras no YouTube, Instagram e TikTok) e consultar as estatísticas desses canais. O app não é oferecido ao público.

2. Dados acessados

O app acessa somente as contas do próprio projeto Doze Cadeiras, com a autorização do dono:

  • YouTube (YouTube API Services): envio de vídeos ao canal e leitura de dados públicos do canal (título, inscritos, número de vídeos, visualizações).
  • Instagram (Meta): publicação de Reels e carrosséis e leitura de estatísticas da conta.
  • TikTok: publicação de vídeos e leitura de estatísticas da conta.

Não coletamos dados de outras pessoas, de espectadores ou de seguidores.

3. Como os dados são guardados

As chaves de acesso ficam apenas no computador do autor, fora de qualquer servidor ou repositório público. Nenhum dado é vendido, compartilhado ou usado para publicidade.

4. YouTube API Services

Este app usa os YouTube API Services. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions (Google/YouTube), nas configurações de apps do Instagram e nas configurações de apps do TikTok. Ao revogar, as chaves guardadas deixam de funcionar e são apagadas.
