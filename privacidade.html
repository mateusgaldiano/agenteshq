Política de privacidade

Última atualização: 24 de outubro de 2026.

Quais dados o AgentesHQ acessa

Com a autorização do usuário, o AgentesHQ acessa a Google Agenda dele (escopo https://www.googleapis.com/auth/calendar) para ler, criar, editar e apagar eventos.

Onde os dados ficam

  • O AgentesHQ roda no computador do usuário. Não existe servidor do AgentesHQ na internet.
  • A autorização do Google (token) fica salva só nesse computador.
  • Os eventos são buscados direto da API do Google quando o usuário ou um agente precisa deles.

Com quem os dados são compartilhados

Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, com uma exceção: quando o usuário pede algo a um agente que envolve a agenda, os eventos necessários para responder são enviados ao modelo de inteligência artificial que o agente usa (Claude, da Anthropic), só para gerar aquela resposta.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar o arquivo google/token.json no computador também desconecta o app.
